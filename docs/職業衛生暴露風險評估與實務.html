二、職業衛生與暴露評估：範疇、定義與框架

職業衛生的科學本質：ARECC 框架

職業衛生管理遵循 ARECC 框架：

階段 內容 實務重點
Anticipate 預期 規劃階段先行介入，分析潛在危害
Recognize 辨識 識別既存有害因子（化學、物理、生物、人因、心理）
Evaluate 評估 定量採樣、定性判斷、建立暴露實態
Control 控制 工程改善、管理手段、行政變革
Confirm 確認 再評估確保控制有效且風險可接受

這五階段構成風險管理的基石，也是暴露評估的邏輯主軸。

暴露評估的核心定義與流程

職業衛生暴露評估是一個系統性過程：

  • 核心目標：評估勞工對各類危害因子的接觸強度（濃度/能級）、頻率與持續時間，推估總暴露量
  • 比對標準：與職業暴露限值（OELs）或專業準則比較，判定風險接受程度
  • 最終目的：決定是否需要介入控制措施

暴露評估不是一次性的採樣，而是持續的風險管理循環。

暴露評估的五大範疇

現代暴露評估已擴展至五大範疇，涵蓋 Total Worker Health：

類別 危害因子舉例
化學性 粉塵、有機溶劑、特定化學物質
物理性 噪音、振動、輻射、極端溫度
生物性 細菌、真菌、病毒、生物氣膠
人因性 不良姿勢、重複動作、過度施力
社會心理 工作壓力、工作負荷、輪班制度

基本特性描述

評估前必須建立的三大面向：

  1. 工作場所與流程特性
    • 製程原理、作業型態、工程控制、組織架構與工作節奏
  2. 危害因子特性
    • 物質毒性、物理能級、生物致病性、人因負荷、心理壓力源
  3. 勞動力特性
    • 人員數量、位置、班制、作業習慣、壓力調適能力

基本特性描述是後續 SEG 劃分與採樣策略的基礎。

多元化的評估方法論

針對不同因子，採取對應的科學工具：

因子類別 評估方法
化、物、生 環境監測、生物監測
人因工程 RULA、REBA、KIM 量表，動作捕捉，力學計算
社會心理 標準化問卷（過勞量表）、訪談、組織行為觀察

暴露評估從「單純採樣」升級為「策略性管理流程」。

暴露風險評估的整體框架

暴露評估是風險評估（Risk Assessment）的核心環節：

危害鑑別 → 暴露評估 → 劑量反應評估 → 風險特徵化

  • 整合統計學、毒理學、人因工程與管理科學
  • 確保勞工在安全、健康且人性化的環境中工作

三、職業暴露限值 (OEL) 的性質與應用

OEL 的類型與定義

OEL 類型 縮寫 定義與應用
時量平均值 TWA 8 小時工作日的加權平均濃度，評估長期健康風險
短時間暴露限值 STEL 15 分鐘加權平均，防止刺激或麻醉效應
最高容許濃度 Ceiling 任何時間不得超過，用於急性毒性物質
行動水平 Action Level 通常為 OEL 的 50%，啟動管理措施門檻

OEL 並非安全/危險的絕對分界線，個體感應性存在差異。暴露評估的終極目標是 ALARA 原則（盡可能合理降低暴露）。

四、暴露評估的步驟與實務流程（AIHA 策略）

第一階段：策略啟動與政策確立

  • 確立企業職業衛生政策目標
  • 定義專業人員角色職權
  • 制定書面標準作業程序（SOP）
  • 將職業衛生納入企業風險管理（ERM）體系

第二階段：基本特性描述（多維度）

  • 製程與任務：設備參數、物料理化特性、人機介面配置
  • 勞動力：職位、任務頻率、路線、持續時間、PPE 使用、輪班節奏
  • 環境：通風設施效能、物理環境、組織文化與支持系統

第三階段：建立相似暴露族群 (SEG)

  • SEG 定義：執行任務相似、接觸化學品一致、暴露環境均質的勞工群組
  • 劃分標準超越職稱：
    • 物質因子：接觸一致性、環境均質性
    • 人因因子：動作相似性、重複頻率
    • 心理因子：任務壓力、組織層級一致性

SEG 是暴露評估的核心組織單元，能減少群組內暴露變異，提高評估效率。

第四階段：初步暴露評量與決策

利用結構化工具或統計方法，將 SEG 歸類為 暴露控制類別（ECC 0~4）：

ECC 定義 對應行動
0 95th < 檢測極限 可接受
1 < 10% OEL 可接受
2 10–50% OEL 不確定，需進一步資訊
3 50–100% OEL 不可接受，立即介入
4 > OEL 不可接受，強制控制

第五階段：進一步資訊收集與量化監測

  • 優先選擇全工作時段個人採樣
  • 運用數學建模（Modeling）推估暴露
  • 人因：RULA、KIM 等量表
  • 心理：標準化過勞量表
  • 統計推論：計算 95th Percentile、UCL95

第六階段：健康危害控制實施

層級控制（Hierarchy of Controls）與 ALARA 原則：

  1. 消除與替代：移除有害源、改用低毒物料、自動化
  2. 工程控制：局部排氣、隔絕噪音、人因設計優化
  3. 行政管理：縮短工時、教育訓練、工作輪換
  4. 個人防護具：最後一道防線

第七階段：動態重新評估與確認

  • 當製程變更、原料更換、健康異常或組織調整時，立即重啟評估
  • 定期再評估（如 ECC 1 每三年一次）
  • 完整記錄評估過程、數據與決策邏輯，形成企業知識庫

五、暴露評估的資料收集與技術方法

環境與生物媒介因子：定量監測與採樣

  • 個人採樣：佩戴於呼吸帶，反映真實吸入濃度，法定合規基礎
  • 區域採樣與即時監測：評估污染源排放、工程控制效能，直讀式儀器可偵測尖峰暴露
  • 生物監測：分析尿液、血液中的代謝物，評估所有途徑的總劑量

採樣必須考慮空間變異與時間變異。

數學建模的科學推估

適用於無法量測或新製程規劃：

  • 吸入暴露模型：單區域/雙區域模型、AIHA SDM2.0™
  • 皮膚暴露模型：IHSkinPerm™，評估經皮吸收貢獻

建模是補足現場監測限制的重要工具。

人因與社會心理因子的評估方法

  • 人因：
    • 結構化觀察量表：RULA、REBA、KIM
    • 數位化量測：錄影分析、穿戴式感測器（EMG）
  • 社會心理：
    • 標準化量表：過勞量表、職場永續健康量表
    • 人員訪談與組織審查，將主觀感受轉化為可分析指標

專業判斷的精進：改善暴露判斷（IEJ）框架

  • 問題：專業判斷容易受認知偏差影響（過度自信、最近事件偏誤）
  • IEJ 框架：
    • 反饋循環：將定性判斷與實際量測數據對比
    • 統計修正：運用統計工具修正判斷閾值，持續校準訓練

確保評估結論具備科學再現性與一致性。

六、統計分析方法與決策

環境與生物媒介因子的對數常態分佈理論

暴露數據通常呈右偏態，以對數常態分佈描述：

  • 若 (X) 服從對數常態，則 (Y = \(ln(X)\)) 服從常態分佈（均值 (\(𝝁\))，變異數 (\(𝛔^2\))）
  • 幾何平均值 (GM)：代表暴露的中位水平
  • 幾何標準差 (GSD)：代表暴露的變異程度；GSD > 3 表示 SEG 劃分過寬

決策不是看單一數據是否低於 OEL，而是看整個 SEG 的暴露分佈是否在統計上合規。

核心統計指標與決策門檻

指標 定義 決策標準
第95百分位數 (\(X_{95}\)) 95% 暴露值低於此值 (\(X_{95}\) < OEL) 視為合格
95% 置信上限 (\(UCL95\) ) 考慮樣本數的保守估計 \(UCL95\) < OEL
超標比例 (Exceedance Fraction) 暴露超過 OEL 的機率 通常要求 <5%

統計工具與貝氏應用

工具 功能 適用情境
IHSTAT® 計算 GM、GSD、(\(UCL95\) )、常態檢定 基礎採樣數據 (n≥6)
Expostats 貝氏模型、處理未檢出值、評估勞工間變異 小樣本、多重 LOD、複雜決策
Tool 2 (Expostats) 評估組內與組間變異 驗證 SEG 劃分有效性

貝氏統計：( \(\text{Posterior} \propto \text{Likelihood} \times \text{Prior}\))
允許整合專業判斷與歷史數據，計算超標機率。

人因與社會心理因子的統計與決策

  • 分佈特性：正態分佈或序位數據
  • 人因：峰值負荷、累積負荷，RULA/REBA 得分比例
  • 心理：與常模比較，t 檢定、相關分析
  • 決策門檻：
    • 人因：高風險級別勞工比例 >20% → ECC 3/4
    • 心理：SEG 平均得分高於全國常模 1 個標準差 → 風險不可接受

統計工具之綜合應用

類別 工具 核心功能
全範疇 貝氏決策分析 (BDA) 整合判斷與數據，計算 ECC 等級機率
環境媒介 Expostats / IHDA 處理對數常態、小樣本、未檢出值
人因心理 SPSS / R 描述統計、信效度分析、差異檢定
動態評量 機器學習 / 混合模式 預測長期損傷或耗竭趨勢

將所有因子的結果轉化為統一的 ECC，用一致的語言陳述風險。

暴露控制類別（ECC）詳細定義（化、物、生）

ECC 95th Percentile 範圍 風險等級 建議行動
0 < 檢測極限 可忽略 常規管理
1 < 10% OEL 低風險 定期再評估
2 10-50% OEL 中等，不確定 進一步監測或建模
3 50-100% OEL 高風險 優先工程控制
4 > OEL 極高風險 立即停止暴露，強制控制

決策分析要點

  • 定量決策：有足夠數據（n≥5，設限比例<80%）時，優先使用統計方法（尤其是貝氏）
  • 定性決策：缺乏數據時，使用結構化方法（如 SDM 2.0），避免直觀判斷
  • 心理偏誤校正：採用 Kahneman「快思慢想」理論，記錄判斷依據並與後續數據比對，建立回饋迴路
  • 資源優化：根據風險等級制定優先順序，控制分級策略可提前進行危害優先排序

七、2026 年台灣職業衛生監測制度之修法重點與實務應用

核心修法意涵：從形式合規邁向風險管理

  • 監測評估小組強制化：
    • 門檻由 500 人下修至 300 人
    • 成員包含職業衛生技師、職安人員及勞工代表
    • 統籌監測計畫與 SEG 建立
  • 職業衛生技師專業簽證制度：
    • 技師不得為監測機構內部人員，確保獨立性
    • 對採樣策略提供建議，簽證負連帶責任
    • 需完成 54 小時專業課程及每年持續進修
  • 監測頻率彈性化：
    • 低風險（ECC 1）且管理優良得申請調整頻率
    • 通報期限延長至 45 日，確保數據分析品質

職業衛生技師之角色重塑

  • 由「數據採集技術員」提升為 「策略風險顧問」
  • 技術簽證人：獨立簽署報告，應對法律訴訟
  • 製程優化者：提供成本效益導向的工程改善建議
  • 跨專業橋樑：協調職醫、職安與勞工，將科學數據轉化為行動

  • 全面健康管理：涵蓋人因、熱壓力、噪音、輻射、社會心理

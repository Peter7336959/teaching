1.2 三大核心法源依據

1.1.A 傳統「末端管理」的限制

舊法的管理架構

  • 我國《勞工安全衛生法》（63年公布施行）時期，機械安全管理係以「雇主」為法律責任主體，僅規範使用端的雇主與勞工之間的權利義務關係，此種管理模式常被稱為「末端管理」。

末端管理的本質缺陷

  • 責任歸屬問題：雇主對防止機械、設備或器具等引起之危害，應有符合規定之必要安全衛生設備及措施。此種管理模式將機械設計製造階段的潛在風險，轉嫁由使用端的雇主與勞工承擔。
  • 現實困境：政府不能坐視有安全缺陷之機械不斷生產出廠或輸入、低價傾銷流入市面，而無安全把關機制。
  • 法規演進的必然：我國於102年修法將責任向上游延伸，要求設計、製造或輸入者於源頭階段實施風險評估。

1.1.B 災害根源：機械設計、製造階段的缺陷

災害發生的真實原因

  • 機械災害事故多源於機械之構造、性能，或防護不足或有缺陷所致。許多職業災害的根源並非操作不當，而是機械本身在設計製造階段就存在安全缺陷。

國內數據佐證

  • 以我國動力堆高機為例，2011年至2024年相關媒介物職災計有146件，其中被撞42件（30.2%）、崩塌30件（21.6%）、墜落25件（18%）、物體飛落18件（12.9%）、被捲12件（8.6%）。

源頭管理的核心思維

  • 安全責任不應僅由雇主承擔，作業的安全應藉由機械本身的安全性能來加以提升。

1.1.C 國際趨勢：禁止無安全裝置的機械流通

國際勞工組織（ILO）的核心規範

  • 機器防護公約（第119號公約，1963年）
    • 一切動力驅動的機器，無論新舊，均應適用本公約之規定
    • 具有危險部件而無適當防護的機器，其銷售和租賃均應由國家法律或條例予以禁止
    • 無適當防護的機器的任何其他形式的轉讓和展出均應予以禁止
    • 保證遵守規定的義務應由製造商、賣方、出租人等承擔
  • 機器防護建議書（第118號建議書，1963年）
    • 在設計機器時，即應考慮相關防護規定

國際間的具體實踐

  • 歐盟的「機械安全指令」、日本的「總括性安全基準之機械相關指針」，均要求設計製造階段即符合安全要求。

1.1.D 我國里程碑：102年《職業安全衛生法》修正

立法歷程

  • 102年7月3日，總統令公布《職業安全衛生法》（原名《勞工安全衛生法》全文修正）
  • 增列「機械源頭管理制度」，為我國機械安全管理建立劃時代里程碑
  • 於103年7月3日及104年1月1日分兩階段施行

修法核心

  • 擴大適用範圍、建構機械設備器具及化學品源頭管理制度、健全職業病預防體系、強化高風險事業製程安全評估監督機制及提高違法事項罰則

配套子法規

  • 機械設備器具安全標準
  • 機械設備器具安全資訊申報登錄辦法
  • 機械類產品型式驗證實施及監督管理辦法
  • 機械設備器具監督管理辦法

1.2 三大核心法源依據

第5條（源頭風險評估）

設計、製造、輸入者應實施風險評估

第7條（指定產品申報登錄）

製造、輸入者須符合安全標準，上網申報登錄並張貼安全標示（TD標示）

第8條（公告產品型式驗證）

製造、輸入者須經驗證機構合格，張貼合格標章（TC標章）

簡報小結：第7條是一般性指定產品，第8條是高風險或特定的公告產品

1.2.A 第5條：源頭風險評估義務

職業安全衛生法第5條第2項

「機械、設備、器具、原料、材料等物件之設計、製造或輸入者及工程之設計或施工者，應於設計、製造、輸入或施工規劃階段實施風險評估，致力防止此等物件於使用或工程施工時，發生職業災害。」

立法目的

  • 要求上游業者具有本質安全之概念，於設計、製造、輸入階段實施風險評估，以事前消除危害根源

「風險評估」的定義

  • 國際標準ISO 31000定義「風險評估」為風險辨識、分析及評量之過程

源頭管制的第一道防線

  • 第5條是機械源頭管理的基礎性規範，為第7條與第8條的具體管制措施奠定法理基礎

1.2.B 第7條：指定產品申報登錄制度（TS制度）

職業安全衛生法第7條

  • 第1項：「製造者、輸入者、供應者或雇主，對於中央主管機關指定之機械、設備或器具，其構造、性能及防護非符合安全標準者，不得產製運出廠場、輸入、租賃、供應或設置。」
  • 第3項：「製造者或輸入者對於第一項指定之機械、設備或器具，符合前項安全標準者，應於中央主管機關指定之資訊申報網站登錄，並於其產製或輸入之產品明顯處張貼安全標示，以供識別。」

適用範圍（施行細則第12條）

  • 動力衝剪機械、手推刨床、木材加工用圓盤鋸、動力堆高機、研磨機、研磨輪、防爆電氣設備、動力衝剪機械之光電式安全裝置、手推刨床之刃部接觸預防裝置、木材加工用圓盤鋸之反撥預防裝置及鋸齒接觸預防裝置等，合計12種機械設備器具。

1.2.B 申報登錄制度重點（續）

資訊網站

  • https://tsmark.osha.gov.tw

安全標示（TS標示）

  • 完成登錄後，應於產品明顯處（銘版上或鄰近商標、廠牌等易於辨認之位置）張貼安全標示

三大佐證方式

  1. 委託認可檢定機構實施型式檢定合格
  2. 委託經認證之產品驗證機構審驗合格
  3. 製造者完成自主檢測及產品製程一致性查核

其中防爆燈具、動力衝剪機械等六種產品，僅得以型式檢定合格方式為之

法律責任

  • 申報者如有申報不實情事，須負刑法使公務員登載不實罪或偽造文書罪責

1.2.C 第8條：公告產品型式驗證制度（TC制度）

職業安全衛生法第8條第1項

「製造者或輸入者對於中央主管機關公告列入型式驗證之機械、設備或器具，非經中央主管機關認可之驗證機構實施型式驗證合格及張貼合格標章，不得產製運出廠場或輸入。」

「型式驗證」的定義（施行細則第13條）

  • 型式驗證，指由驗證機構對某一型式之機械、設備或器具等產品，審驗符合安全標準之程序

核心特色

  • 以產品之「型式」為驗證對象，同一型式通過驗證後，無須逐批檢驗，兼顧安全把關與行政效率

驗證合格證明書效期

  • 有效期間為三年，期滿前三個月內得申請展延三年

1.2.C 第8條制度重點（續）

合格標章（TC標章）格式

  • 圖式由字軌TC、指定代碼及發證機構代號組成，顏色為黑色K0
  • 應張貼於本體明顯處，使用不易變質之材料，字體內容清晰可辨且不易磨滅，並以牢固之方式標示

彈性機制

  • 免驗證：國防軍事用途、科技研發測試、商業樣品或展覽品、加工後復運出口等情形，得申請免驗證
  • 先行放行：因驗證需求，得向中央主管機關申請先行放行
  • 特殊構造規格：得檢附產品安全評估報告，申請核准採用適當檢驗方式為之

禁止行為（第9條）

  • 未經型式驗證合格之產品或型式驗證逾期者，不得使用驗證合格標章或易生混淆之類似標章

2.1 什麼是「自我宣告制度」？

對應法條：職安法第7條

概念

  • 製造/輸入者自行宣告產品符合安全標準，並上網登錄、張貼標示

目的

  • 提供產品符合安全的保證，建立市場責任機制

指定產品的範圍（施行細則第12條）

  • 合計12種機械設備器具，應符合「機械設備器具安全標準」之規範，始得產製運出廠場、輸入、供應、租賃或設置

法律責任

  • 違反第7條第1項或第3項規定者，依第44條規定，處新臺幣三萬元以上三十萬元以下罰鍰；情節重大者，得公布其名稱及負責人姓名

2.1.B 上網登錄、張貼標示

TS安全標示

  • 完成登錄後，製造者或輸入者應於產品明顯處（銘版上或鄰近商標、廠牌等易於辨認之位置）張貼安全標示

安全標示格式

  • 由圖式及識別號碼組成；識別號碼應繫於圖式之右方或下方，且由字軌TD及指定代碼組成
  • 指定代碼應向中央主管機關申請核發

標示要求

  • 使用不易變質之材料、字體內容清晰可辨且不易磨滅，並以牢固之方式標示

實務案例

  • 以研磨機（砂輪）為例，嘉寶自然工業股份有限公司自2015年1月1日起，所有製造之產品一律標示安全標示圖與識別碼，無標示者無法出貨

2.1.C 建立市場責任機制

制度設計的核心目的

  1. 阻絕不安全產品流入市場
    • 明定製造者或輸入者對於指定之機械、設備或器具符合安全標準者，應於資訊申報網路登錄，始得運出產製廠場或輸入
  2. 建立產品安全資訊透明化
    • 自我宣告制度有助於明確區隔產品之安全良否，並可促進產品安全資訊透明化

申報登錄應備文件

  • 符合性聲明書（簽署該產品符合安全標準之聲明）
  • 設立登記文件（工廠登記、公司登記等證明）
  • 測試證明文件（型式檢定合格證明書、審驗合格證明或產品自主檢測報告）
  • 產品基本資料（型錄、外觀圖說、規格、安裝操作說明書）
  • 安全裝置資料（品名、規格、安全構造、性能說明）

2.2 誰需要申報？哪些產品？

指定產品（施行細則第12條）

  • 動力衝剪機械
  • 手推刨床
  • 木材加工用圓盤鋸
  • 動力堆高機
  • 研磨機/研磨輪
  • 防爆電氣設備
  • 動力衝剪機械之光電式安全裝置
  • 手推刨床之刃部接觸預防裝置
  • 木材加工用圓盤鋸之反撥預防裝置及鋸齒接觸預防裝置

輸入管制

  • 經濟部國際貿易局已將相關產品增列輸入規定代碼「375」，納入邊境管制

2.2.B 例外免申報情形

法源依據：機械設備器具安全資訊申報登錄辦法第2條

指定產品有下列情形之一者，得免申報登錄：

  1. 供國防軍事用途者
  2. 供科技研發、測試用途之專用機型
  3. 供商業樣品、展覽品供參觀者
  4. 供加工、組裝後全數復運出口者
  5. 專供外銷者
  6. 其他經中央主管機關指定者

免申報之程序要求

  • 輸入者應備具產品用途聲明書，向中央主管機關申請專用通關證號代碼

免申報不等於免安全：產品本身仍應符合安全標準

2.3 如何完成申報登錄？（三大佐證方式）

方式A：型式檢定合格（委託認可檢定機構）

方式B：產品驗證審驗合格（委託認證驗證機構）

方式C：自主檢測 + 製程一致性查核

重點提醒：防爆電氣設備等六種產品僅能採方式A

2.3.A 方式一：型式檢定合格

法源依據：《機械設備器具安全資訊申報登錄辦法》第4條第1項第1款

何謂「型式檢定」？

  • 型式檢定係指由中央主管機關「認可」之檢定機構，針對某一「型式」之產品，依據安全標準進行審驗

強制適用範圍（僅得採用本方式）

  1. 防爆燈具
  2. 防爆電動機
  3. 防爆開關箱
  4. 動力衝剪機械
  5. 木材加工用圓盤鋸
  6. 研磨機

採用本方式的理由

  • 上開6種產品因具有高風險特性，立法者要求最高等級的第三方把關

2.3.B 方式二：產品驗證審驗合格

法源依據：《機械設備器具安全資訊申報登錄辦法》第4條第1項第2款

何謂「產品驗證」？

  • 產品驗證係指由「認證組織」認可之「產品驗證機構」，對產品進行審驗，確認其符合安全標準之程序

與「型式檢定」之區別

項目 型式檢定 產品驗證
機構認可 勞動部認可 TAF等認證組織認證
適用產品 強制6種高風險產品 其他指定產品
性質 最高管制強度 一般管制強度

何謂「認證組織」？

  • 常見TAF（全國認證基金會）、國際認證論壇（IAF）會員機構等

2.3.C 方式三：自主檢測＋製程一致性查核

法源依據：《機械設備器具安全資訊申報登錄辦法》第4條第1項第3款

制度設計之緣由

  • 參照歐盟CE標誌之自我宣告精神，允許製造者自行完成檢測及查核，減少第三方驗證之行政成本與時間

三大資格條件（第4條第3項）

  1. 製造者設置之檢測實驗室，應經國內外認證組織認證
  2. 產品製程一致性查核，應由國內外認證組織認證之相關機構執行
  3. 執行檢測與查核之人員，應具備相關知能並經認證機構評鑑合格

自主檢測 ≠ 製造者自己檢測：檢測實驗室、查核機構、檢測人員均須經「認證」

六種產品不得採本方式：防爆燈具、防爆電動機、防爆開關箱、動力衝剪機械、木材加工用圓盤鋸及研磨機

2.4 申報登錄的義務與責任

2.4.A 安全標示（TD標示）

法源依據：《安全標示與驗證合格標章使用及管理辦法》第3條、第5條、第6條、第7條

  • 格式：圖式 + TD000000（指定代碼）
  • 張貼位置：本體明顯處（銘版或商標旁）
  • 材質要求：不易變質 + 清晰可辨 + 牢固

2.4.B 申報者責任

確保資料真實性

  • 申報資料須加蓋承辦者及其負責人印章
  • 電子檔格式限於不可編輯之圖檔或PDF檔
  • 刑事責任：刑法第214條使公務員登載不實罪、偽造文書罪

2.4.B 申報者責任（續）

技術文件保存義務

  • 法源依據：《機械設備器具安全資訊申報登錄辦法》第11條
  • 申報者應保存所登錄之產品符合性聲明書及相關技術文件，至該產品停產後至少十年

登錄內容變更之申報義務

  • 法源依據：《機械設備器具安全資訊申報登錄辦法》第9條
  • 登錄內容有變更者，應自事實發生日起三十日內，申請變更登錄

2.4.C 登錄效期

  • 法源依據：《機械設備器具安全資訊申報登錄辦法》第14條
  • 效期範圍：三年以上七年以下
  • 效期屆滿前三個月內得申請展延
  • 效期屆滿而未申請展延者，應重新申報登錄

2.5 輸入產品的邊境管制與先行放行

2.5.A 邊境管制

法源依據：《機械設備器具安全資訊申報登錄辦法》第5條之1、第5條之2

我國做法

  • 透過邊境管制之單證比對程序，由海關配合堵截有安全顧慮或未完成上網申報程序之產品通關入境

輸入規定代碼「375」

  • ＝未完成申報登錄，不得進口
  • ＝海關協助源頭管理的第一道防線

實施成效

  • 以動力堆高機為例，自108年7月1日納入邊境管制後，累計申報登錄安全資訊已有19,500餘筆申報資料，超過180餘家登錄廠商

2.5.B 先行放行

法源依據：《機械設備器具安全資訊申報登錄辦法》第5條之1

為何需要先行放行？

  • 輸入產品在邊境被管制時，如因尚未取得測試合格證明而須退運，衍生龐大運輸成本及交貨違約之國際貿易糾紛

先行放行後的義務與期限

  • 存放限制：「先行放行之產品符合型式驗證規定前，不得運出產品之設置或儲存地點，亦不得啟用或移轉於第三人」
  • 期限規定：輸入後一年內完成登錄安全資訊
  • 違規處理：處最高新臺幣200萬元罰鍰，得按次處罰

重點歸納：先行放行＝先放行、後檢驗，但產品須限制存放地點，且須於一年內完成登錄，違者不得使用或販售

3.1 什麼是「型式驗證」？

對應法條：職安法第8條

概念

  • 由第三方「驗證機構」對產品型式進行審驗，合格後發證、張貼標章

與自我宣告的區別

  • 更嚴格的第三方把關，適用於風險較高的公告產品

現行公告產品範例

  • 交流電焊機用自動電擊防止裝置（自107年7月1日起適用）

3.1.A 職安法第8條

第8條第1項

「製造者或輸入者對於中央主管機關公告列入型式驗證之機械、設備或器具，非經中央主管機關認可之驗證機構實施型式驗證合格及張貼合格標章，不得產製運出廠場或輸入。」

立法目的

  • 對風險較高之機械、設備或器具產品，透過第三方驗證機構之專業審查，於產品上市前即建立安全把關機制

授權子法

  • 機械類產品型式驗證實施及監督管理辦法
  • 機械類產品申請免驗證辦法
  • 機械類產品申請先行放行辦法

3.1.B 第三方驗證機構對產品型式進行審驗

「型式驗證」的定義

  • 依《職業安全衛生法施行細則》第13條：「型式驗證，指由驗證機構對某一型式之機械、設備或器具等產品，審驗符合安全標準之程序。」

驗證合格證明書

  • 驗證機構實施產品型式驗證，經審驗合格者，應發給附字號之型式驗證合格證明書，有效期間為三年

「型式」的意義

  • 型式驗證以產品之「型式」為驗證對象，避免逐批檢驗方式下對同一型式產品重複檢驗，兼顧安全把關與行政效率

3.1.C 與自我宣告的區別

比較項目 第7條（自我宣告） 第8條（型式驗證）
適用範圍 指定產品（12種） 公告產品（高風險）
驗證方式 自我宣告+三大佐證方式 第三方驗證機構審驗
標章 TS標示 TC標章
管制強度 較低 較高
責任主體 製造者/輸入者自行宣告 驗證機構確認合格

重點歸納：自我宣告（第7條）→ 製造者對自己負責；型式驗證（第8條）→ 第三方驗證機構為安全把關

3.2 型式驗證的流程與要求

法源依據：《機械類產品型式驗證實施及監督管理辦法》第3條

報驗義務人

  • 國內產製者或國外輸入者

產製定義

  • 指：生產、製造、加工或修改，包括將機械類產品由個別零組件予以組裝銷售、於進入市場前為銷售目的而修改

申請文件

  • 符合性聲明書、產品基本資料、設立登記文件、符合性評鑑證明

驗證實施程序

  • 包含產品設計及製造階段的符合性評估

合格證明書效期

  • 3年，期滿前可申請展延3年

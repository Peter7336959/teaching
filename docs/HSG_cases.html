HSG53 呼吸防護裝備（RPE）案例學習

附錄5：適當與適合的 RPE 選用實例

Author

職安衛專業人員教學用

前言

本文件整理 HSG53《工作中的呼吸防護裝備實用指南》附錄5 的三個案例，供職安衛專業人員教學使用。

每個案例均依照以下邏輯鋪陳：

學習目標： 學員能從危害評估出發，計算所需防護係數（APF），並綜合考量佩戴者、任務與環境，選出適當且適合的 RPE。

案例一：切割混凝土路緣石

作業背景

  • 在某段 300 公尺長的道路上鋪設路緣石。
  • 設計中指定交通寧靜化措施，需在短距離內以不同角度鋪設，形成狹窄路段與優先通行區。
  • 標準路緣石運到工地後，需依尺寸裁切。
  • 使用水抑制降低粉塵，但現場無自來水，使用附泵浦的水瓶。
  • 裁切作業每次約 5 分鐘，屬於間歇性作業。

危害識別

  • 裁切路緣石、鋪路石或磚塊會產生大量石塵。
  • 石塵中含有極細的可呼吸性結晶型二氧化矽（RCS）。
  • 暴露於 RCS 可能導致：
    • 矽肺症
    • 肺癌
    • 慢性阻塞性肺病（COPD）

危害重點： RCS 是造成塵肺症與肺癌的關鍵物質，即使短時間暴露也不可輕忽。

可用資訊

  • 沒有 SDS。
  • 找到 COSHH 指引表 CN6「使用旋轉切割機切割鋪路石與路緣石」。
  • CN6 建議：
    • RPE 的 APF = 20
    • 需併用護目鏡與聽力防護

適當性評估

對本作業而言，適當的 RPE 包括：

RPE 類型 防護係數
一次性半面罩呼吸器 20
可重複使用半面罩呼吸器（顆粒物濾材） 20

密合度評估

  • 面罩為密合型。
  • 兩名勞工：
    • 乾淨剃鬚
    • 無面部標記
    • 不戴眼鏡
  • 需其他 PPE，相容性很重要：
    • 安全帽附耳罩，不干擾 RPE 帶子
    • 護目鏡不干擾鼻樑處
  • 作業間歇、戶外溫度正常 → 密合型面罩足夠。
  • 須做密合度測試。

決策

最終選擇： 一次性半面罩呼吸器（前提：兩名勞工都能取得足夠密合）。

重點

  • 沒有 SDS 時，可改用 COSHH 指引表取得 APF 建議。
  • 間歇、短時間、環境正常 → 密合型面罩即可。
  • 其他 PPE 的相容性不可忽略。
  • 即使作業時間短，密合型面罩仍須密合度測試。

案例二：印刷廠改用新膠黏劑

作業背景

  • 工廠贏得高品質印刷新合約。
  • 改用新的網版印刷膠黏劑。
  • 一名操作員在印刷機上工作。
  • 已使用局部排氣通風（LEV）。
  • 操作員每小時進入 LEV 捕集區 10 分鐘。
  • 雖有 LEV，仍可能有低濃度暴露。

危害識別

膠黏劑成分：

成分 CAS No. % by Wt
醋酸乙烯酯與丙烯酸酯共聚物 商業機密 40–70
水 7732-18-5 15–40
異丙醇 67-63-0 <0.3
醋酸乙烯酯 108-05-4 <0.2
壬基酚聚氧乙烯醚乙醇 9016-45-9 <0.1
  • 醋酸乙烯酯：IARC 分類 Grp 2B：可能人類致癌物。
  • 游離醋酸乙烯酯單體是此作業的關鍵關注物質。

危害重點： Grp 2B 致癌物，暴露應盡量降低，RPE 選擇須謹慎。

可用資訊

  • SDS 建議：
    • 半面罩或全面罩過濾式呼吸器
    • 搭配有機蒸氣濾罐

適當性評估

RPE 類型 濾材
可重複使用半面罩 氣體/蒸氣濾材
全面罩 氣體/蒸氣濾材

密合度評估

  • 面罩為密合型。
  • 勞工：
    • 乾淨剃鬚
    • 無面部標記
    • 不戴眼鏡
  • 作業間歇、溫度正常 → 密合型面罩足夠。
  • 須做密合度測試。

決策

最終選擇： 可重複使用半面罩呼吸器 + A2 型氣體/蒸氣濾材（前提：勞工能取得足夠密合）。

重點

  • SDS 是選擇 RPE 的重要起點，會直接建議濾材類型。
  • 即使有 LEV，進入捕集區仍可能有殘留暴露。
  • 致癌物暴露應盡量降低。
  • 半面罩 + A2 濾材是常見組合，仍須密合度測試。

案例三：小型黑色鑄造廠打磨作業

作業背景

  • 小型鑄造廠按單生產金屬產品，原料為廢金屬。
  • 重要環節：打磨粗邊（fettling）。
  • 四名操作員使用研磨機處理成品。
  • 已使用 LEV，員工可能工作長達 8 小時。
  • 作業性質使高濃度粉塵始終存在。

危害識別

  • 粉塵：鐵質鑄造顆粒物（二氧化矽 + 金屬氧化物）。
  • 廢金屬 → 粉塵可能含重金屬。
  • 工廠不接受塗漆金屬，降低鉛暴露。
  • EH40 WEL：
    • 可吸入性粉塵：10 mg/m³
    • 可呼吸性粉塵：4 mg/m³
  • 實測暴露值：高達 45 mg/m³

計算所需防護係數

[ = = = 11.25 ]

結論： 需要 APF > 11.25 → 應使用 APF 20 的 RPE。

適當性評估

RPE 類型 防護係數
一次性半面罩 20
可重複使用半面罩（顆粒物濾材） 20
動力呼吸器 + 面罩（顆粒物濾材） 20
動力呼吸器 + 頭罩（顆粒物濾材） 20

COSHH 指引 FD8「大型鑄件打磨」 建議 APF ≥ 40，但實測暴露值顯示不需要這麼高。

密合度評估

  • 勞工：
    • 乾淨剃鬚
    • 無面部標記
    • 不戴眼鏡
    • → 可佩戴任何類型 RPE
  • 但：
    • 作業 > 1 小時
    • 重度手工作業
    • → 動力型呼吸器最適合

決策

最終選擇： 動力型呼吸器 + 頭罩 + 顆粒物濾材，APF 20。
可搭配適當面屏，同時提供眼睛防護。

重點

  • 實測暴露數據是計算 APF 的關鍵，不能只憑指引表建議。
  • 指引表與實測結果不一致時，以實測 + 風險評估為準，並記錄理由。
  • 長時間、高工作速率 → 動力型或寬鬆型 RPE 的舒適性更重要。
  • 可考慮整合式防護（頭罩式呼吸器兼具眼睛防護）。

結語

這三個案例分別展示了 「用 COSHH 指引」、「用 SDS」、「用實測暴露數據」 三種不同的資訊來源，以及 「短時間歇」、「中時間歇」、「長時重度」 三種不同的作業特性，涵蓋 RPE 選用最常見的情境。
